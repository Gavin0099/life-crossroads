# GS 生活世界候選素材

此目錄是獨立原型的分層素材，尚未核定為正式 App 美術。完整提示、來源 hash、尺寸與透明度證據見 `manifest.json`；原圖皆由內建 ImageGen 真實生成，沒有以程式畫圖或離線裁切代替。

- `workshop-background.png`：1536 × 1024，空工坊與住宅庭院背景。
- `characters-atlas-v2.png`：1024 × 1536，五個獨立人物；透明背景已讀像素驗證。
- `characters-atlas-v1.png`：保留被淘汰版本與來源追溯，不應載入原型。

## 載入方式

v2 **不能依 2 × 3 等格裁切**。生成器未遵守格距，請依 manifest 的 `crop_rect_px` 在 SwiftUI / UIKit 呈現時裁切。人物原始 PNG 未離線編修。

Alpha=0 的像素有 1,184,073 / 1,572,864（約 75.28%）。部分檢視器會顯示全透明像素內的褐色 RGB；正確 alpha 合成後那些像素不可見。五個主要人物連通區彼此分開。灰兔與貓分界的極低 alpha 外緣有輕微裁切，alpha ≥16/255 的可見輪廓完整。
