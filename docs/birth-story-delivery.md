# LX-04：不同出生、不同人生

以 PR #12 `3f6cbfb` 為基底，[Draft PR #13](https://github.com/Gavin0099/life-crossroads/pull/13) 是獨立後續切片。維持 Draft/HOLD，不合併、不發布。驗收先定於 [切片契約](birth-story-slice.md)。

## 實際交付

- 首頁「翻開未知的人生」從八國16個虛構家庭等機會抽選；「探索指定出身」保留手選。出生 receipt 記錄候選、Seed、抽選及資料版本，候選排列不影響結果，恢復不重抽。明示示範範圍，沒有使用全球出生人口權重。
- 人生畫面保留可見的角色場景，事件在其下方決策；家庭安排與真正套用的環境準備規則進入13歲創作願望。數值移入準備／結果詳情，眼前選擇與已保存的故事在前。
- 完成原人生後，使用「帶著同一個願望，換個出身」。原局保留，另一局沿用 Seed，全部15次選擇親自完成，隨時可以回看原局並從左上角返回另一段。
- 故事比較先標出兩邊實際的國家／虛構家庭，再呈現創作願望、實際17歲經驗及其他有差異的選擇，再提供完整時間軸與數值依據。沒有遇到後續邀請時，呈現真正抽到的故事，不補造成功。
- 新存檔 schema 3 保護出生 receipt／完整平行雙局；舊 schema 1／2 保持相容，禁止降標。每次保存先重播驗證，再 atomic write，成功才公布到畫面。

## 真正證明了什麼

[八國機讀結果與比較](../artifacts/evidence/birth-story/comparison.md) 使用披露的有界搜尋 Seed 34：32段完整人生（八國 × 13歲四種行動），其餘行動保持休息，全部可重播。

相同家庭模板的日本與肯亞線上成本不同，但紙本成本相同；這組同選線上的17歲事件也相同。紙本／線上的實際練習，則接續不同工作坊；求助／休息在這組人生實際遇到班上表演。這是機制與呈現的見證，**不是八國長期故事已足夠不同的證明**，也不是玩家娛樂性驗證。

兩段人生的國家、家庭與後續選擇可能同時不同。共用 Seed 配對共有機會，不保證所有事件相同，也不能將全部差異歸因於出身或某一步選擇。

## 產品驗收邊界

| 使用者要求 | 本片交付 | 尚未證明 |
| --- | --- | --- |
| 出生不能自己決定 | 主要入口抽出示範家庭，處境與 Seed 一起保存 | 不是全球出生分布；16情境仍沿用兩類家庭模板 |
| 先看到生活，再思考選擇 | 角色場景常駐、行動在前、成本可展開 | 八國仍共用明示的想像場景，未做國家實景 |
| 同願望、不同限制與支持 | 使用真正套用的家庭／連線／供電規則說明13歲準備 | 不能把成本不同當成長期路線一定不同 |
| 記得以前的選擇 | 真正被抽到的17歲事件與已保存故事事實 | 求助、休息與生活重心尚需更多可感知的長期故事 |
| 如果換個出身 | 原局保留，親玩另一局並比較完整15個決策 | 共用 Seed 不是單因果實驗；後續決策也可能不同 |
| 值得重玩 | 保留可驗證的不同選擇與故事回看 | 10～15歲玩家的期待、理解與主動重玩待實測 |

## 核對方式

1. 從「翻開未知的人生」開始，讀出生處境，確認沒有選國家卻有明確的示範範圍說明。
2. 到13歲比較創作選項與「選擇需要的時間與準備」。選後先看場景／故事，再展開真實計算。
3. 17歲看真正出現的機會；沒有工作坊時不將它當作錯誤。可查「怎麼遇到這件事？」及先前記憶。
4. 完成後換個出身，保留原人生，走完整另一局；比較13、17歲與晚年，確認原局的選項與資源未被改寫。
5. 觀察玩家是否能描述「我做了什麼」「環境限制了什麼」「哪些事不由我控制」，以及是否自發想再玩。這些仍需真人記錄。
