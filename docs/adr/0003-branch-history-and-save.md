# 0003：以歷史重播建立分岔，原局與替代局一同存讀

2026-10-23，LC-04，依使用者授權。已核對 ADR 0001／0002，維持 Domain 不讀檔、分析不改遊戲的邊界。

15個重大決策的歷史足夠短，選前快照以既有 LifeSession 重播重建，不為每次操作新增獨立快照快取或第二套規則。LifeSnapshot 保留完整選前 session；BranchExperiment 保留不可變原局、快照、改選 ID 與獨立可推進的替代局。所有保存或載入的組合都用正式規則重播驗證。若未來歷史長度造成可測量的延遲，再引入帶版本的受驗證快取。

App 讓玩家逐步走完替代人生，不替缺失或失效的原選項自動找替代。比較頁明示後續自由選擇，禁止把整段差異宣稱為單項改選的因果效應。共有候選事件沿用既有版本化亂數鍵，不增加分支 ID／全域抽樣計數到外生亂數中。

本片必須交付原局與分岔續玩的可靠存讀，因此新增 LifePersistence 的最小版本化 JSON 原子保存。一個檔案保存一組人生，不宣稱已完成 LC-06 的 SwiftData 或多存檔管理。這個介面在 LC-06 可換成 SwiftData，前提是同一組重播、版本、損壞與寫入失敗測試仍通過。資料保存先於 UI 狀態更新，寫入失敗保留舊進度與原局。

## 2026-10-27：LX-04 的另一個出身

新增 `ParallelLifeExperiment`，從出生重走另一個家庭情境；原人生仍為不可改寫的值，另一局沿用 Seed 並由玩家逐步選擇，不把原局選項自動套用。`LifeJourney` 同時只保存單局、同出身分岔或不同出身雙局之一；已在雙局時不提供再分岔／再換出身，以免遺失原局。需要替換整組時仍走既有明確確認。

隨機出生使用 `BirthDraw` 的獨立候選亂數鍵，保存候選列表、版本與抽選值；恢復以 catalog 重算驗證。這是可玩示範家庭的等機會抽選，不使用或冒稱人口權重。手選與新 Seed 同背景重玩不冒稱一次新的隨機出生。

含出生 receipt 或平行人生時存檔 schema 3；舊無重心為 1，舊有重心為 2，內容所需版本與標籤不符即拒絕。schema 3 提醒舊 App 不能忽略出生來源或雙局資料。資料、事件、核心規則版本未變；舊局不補造出生 receipt。保存依然整組驗證後 atomic write，成功才公布到 UI。

比較先呈現真實選擇、故事分支及已觸發的線索，保留全15項對照與可展開的資源計算。17歲不保證遇到創作邀請，實際抽到其他事件便呈現其他事件。不同出身、玩家後續行動及重心都可能不同，不能將所有差異歸因於國家或某個起點。
