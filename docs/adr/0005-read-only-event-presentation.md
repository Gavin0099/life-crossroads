# 0005：事件演出只投影已執行紀錄

2026-10-24，單事件視覺整合。已核對 ADR 0001～0004：延續純 Swift 引擎與 I/O 分離、原局與分岔重播、有限資料不補值；沒有取代既有決策。

新增純 Swift `LifePresentation` target，單向依賴 `LifeDomain`。`ProjectMoment` 只接受已套用、已知選項的 `teen-project` trace，提供活動道具、實際成本/資源差、人物互動、故事事實、非零支持、已發生的機會及待發生線索。這不是第二套 resolver；不讀國名、不抽亂數、不保存新狀態、不呼叫網路。獨立 target 讓 trace→畫面契約能在不啟動 SwiftUI 的情況下測試。

`GameStore` 仍先保存、再發佈狀態；選擇前畫面只有活動邀請，選後 `ProjectWorkshopView` 從已發佈的最後一筆 trace 重建。存讀與分岔都沿用同一路徑，不快取演出結果、不改 schema 或引擎/內容版本。未知事件/選項或未套用 trace 不顯示本次演出，保留原有通用回饋。

`applied` 只代表 resolver 已套用那次運算，不是檔案寫入證明（preview 也可能為 true）。「已保存」的來源邊界由 App 僅在 reflecting 階段讀取已發佈 session 保證，另以實際存檔失敗/重試 UI 測試驗證；投影本身不存檔，也不宣稱自行證明持久化。

角色沿用目前 App 的動物原型；工作桌、窗景、道具為 repo-native SwiftUI 圖形與平台 SF Symbols。場景是跨國共用的想像舞台，不描繪真實設備持有率或各國實景。老師僅在本次實際人際互動紀錄存在時出現在回饋圖中；互動不等於額外支持，支持另讀非零 effect step。延後線索不能畫成已獲獎或確定邀請。

此片只驗證一個既有真實遊戲事件，不自動核准其他 Visual WIP，也不宣稱正式美術、兒少理解或實機驗收完成。後續有第二個事件需要時，再決定是否抽共用舞台，現在不做通用演出系統。
