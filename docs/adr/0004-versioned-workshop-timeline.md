# 0004：持續生活切片重用同一引擎，以內容版本隔離排程

2026-10-24，使用者授權GS-05及SIM-01～03，要求13歲紙橋行動延續到15歲可玩機會，圖片關閉後仍成立。

正式預設人生仍採既有15個年齡節點與RNG-V2規則，不將17歲改成15歲。ModelCatalog可帶具穩定ID的DecisionTimeline；內容版本必須以該ID為後綴。選事件、狀態合法性及LifeSession均讀取同一catalog排程，沒有第二套成本、亂數或後果計算。排程隨session保存並在完整重播時與catalog比對；舊session缺少此欄時回到原完整人生排程，跨內容版本不能靜默載入。

LifeData提供有版本的兩事件紙橋內容，原統計與家庭模板不變；新故事的成本、效果、關係與門檻均為明列的設計假設。UI只呈現Domain結果、供觀察場景及發送行動；不以圖片或文案改變可行性。

新切片不是完整P1替代品。之後整合到正式長期事件庫時，需重新審查15歲節點與完整人生節奏，不可將此試玩排程默認套用到原存檔。
