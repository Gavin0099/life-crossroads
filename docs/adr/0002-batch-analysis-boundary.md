# 0002：批次量測由獨立分析層讀取正式人生

2026-10-23，LC-05 量測基線。已核對 ADR 0001，延續純 Swift 引擎與 I/O 分離，沒有取代既有決策。

`LifeAnalysis` 是純 Swift 分析層，依賴 `LifeDomain`，不反向注入遊戲。它以固定背景、Seed 與明示策略操作 `LifeSession`，再讀取真實事件選取、選擇後果與時間跳躍 trace，產出具版本的 `BatchReport`。它不修改成本、事件資格、抽選機率、資源上限或 App 行為。

`LifeDemo` 負責命令列參數、資料載入及 JSON 輸出；Python renderer 只驗證並呈現報告，不能另寫一套遊戲規則。分析使用的策略亂數有獨立 channel，不消耗或改變事件亂數。正式 iOS App 不依賴分析模組。

把分析放在獨立 target，使分母、差異與截斷計算可單獨測試，也避免報告需求擴張核心存檔 schema。分析 schema 和分析版本與遊戲的引擎／內容／資料版本分開保存。固定 Seed 的結果仍受上述遊戲版本約束。

量測是一組實驗樣本，不是國家人口分布、實際玩家策略分布或趣味性分數。不得因為某資源較高就稱某種人生較成功。
