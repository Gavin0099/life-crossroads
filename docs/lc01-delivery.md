# LC-01：資料與可追溯人生規則

使用者於 2026-10-23 明確 GO。維持八國、16 情境、50～70 事件、五階段完整人生的 P1 範圍。
本片交付 Swift Package，不把命令列骨架視為 LC-02 iPhone 可玩版。

## 可執行交付

- `LifeDomain`：CountryProfile、HouseholdProfile、五階段、DecisionResolver、鍵控亂數、LifeState、ConsequenceTrace、時間跳躍與人物呼應。
- `LifeData`：離線 JSON 與原始 WDI 回應；解碼、語意檢查、SHA256 和逐筆來源數值核對。
- `life-demo`：四國八家庭同一 13 歲選擇比較；每個背景走完出生至 80 歲回顧的 15 決策骨架。
- `Tests/LifeDomainTests`：獨立固定預期、邊界、失敗、重播、來源與序列測試；560 段人生骨架 / 8,400 次決策。

核心只接收值；檔案、CryptoKit、Bundle 都留在 Data adapter，UI 尚未加入。
本片四項長期資源為健康、財務安全、人際、技能，各 0～100，沒有合成人生總分。

每個家庭是具 ID 的虛構情境，不是典型家庭，也不是由全國比例抽出的家庭聯合分布。
兩種家庭模板刻意兼有優勢與限制，跨國沿用以利比較；16 個情境不宣稱代表各國家庭多樣性的全貌。
初始健康、財務、人際、技能、設備、交通、照顧安排及支持均引用 `household-scenarios` 設計假設。
未導入死亡、疾病、工資、學制或教育因果統計；未來接入時需新增逐欄來源，不能從這兩項指標推導。

## 真正執行的環境鏈

2023 指標 + 虛構家庭 → 情境摩擦/設備/交通/成人照顧/支持 → 決策成本與可行性 → 實際資源後果與人物呼應。

| 13 歲投入時間一起學習，同為第二種家庭 | 時間成本 | 材料成本 | 健康變化 |
|---|---:|---:|---:|
| 美國 | 3 | 1 | 0 |
| 日本 | 4 | 1 | 0 |
| 印度 | 4 | 1 | 0 |
| 肯亞 | 5 | 2 | -2 |

例如肯亞情境的時間：選擇 3 + 情境網路摩擦 2 + 獨用設備排程 0 + 交通 1 − 他人支持 1 = 5。
材料為選擇 1 + 情境電力摩擦 1 = 2。時間至少 5 的學習觸發健康 −2。
這些門檻和後果均是**透明的設計假設**，沒有宣稱國家比例能證明個人疲勞或成功機率。
同國第一種家庭的互助減少更多準備時間；資金較少並不意味人生價值或所有機會較低。

trace 保存 seed、引擎/資料/內容版本、輸入指標及來源版本、家庭 ID、控制權、規則 ID、
成本調整、資源增減、上下限修正、前後預算、隨機鍵/抽值/門檻與故事來源。
不可行選擇只有報價與拒絕原因，狀態不變，也不產生延遲獎勵。每個事件保留免費休息路線。
「為什麼」文字直接組合執行的規則紀錄，沒有 AI 補寫因果。

童年可表達意願、休息、求助，學習與可信任的大人共同安排；成人工作/照顧責任限 23 歲以上。
照顧負擔不會被當作 8 歲角色應承擔的責任。年齡段是遊戲控制權設定，不是法律判斷。

## LC-02 決策骨架

| 階段 | 決策年齡 | 故事方向 |
|---|---|---|
| 童年 | 8、10、12 | 興趣、朋友、進入新學校；與大人共同安排 |
| 青少年 | 13、17、21 | 共同創作、學習方向、離開熟悉環境 |
| 青年 | 25、32、39 | 工作外學習、生活平衡、共同照顧 |
| 中年 | 45、52、59 | 轉向、互相支持、生活節奏 |
| 晚年 | 65、72、80 | 分享、重新聯絡、人生回顧 |

13、25、45 歲的投入選擇，在 4 歲後由原人物呼應；改選休息便不會產生該條呼應。
同一事件三個選項屬於骨架，尚不能算成 50～70 個完整原創事件。80 歲收束是回顧節奏，不是死亡年齡抽樣。
