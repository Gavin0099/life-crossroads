# UI-10｜方向 Gate（待人類驗證）

本輪主方向採 A：事件卡主導。這依使用者已給的優先方向與可見資訊層級選定，並非宣稱玩家研究已證實。
B 只借簡短章節節奏；C 移到人生地圖。兩研究版保存在檔案與 Preview，不維持三套正式流程。

| 問題 | 目前證據 | 結論界線 |
|---|---|---|
| 第一眼知道要做選擇嗎？ | 「你會怎麼做」和選項已優先；有截圖 | 五秒人測未做 |
| 看起來像遊戲嗎？ | 主流程能選擇、回饋與推進 | 吸引力是待驗主觀判斷 |
| 10～15 歲覺得像教材嗎？ | 沒有兒少參與 | 不宣稱通過 |
| 哪版更有吸引力？ | 同故事三結構可對比 | 不捏造偏好票數 |
| 哪版適合接正式美術？ | A 的事件/選項結構與獨立插畫槽已建立 | 美術與文化審核仍獨立 |

人測方式：10～12 / 13～15 分組，自願、家長知情；交替三版先看順序，內容與尺寸一致。
先展示五秒，再收起，問「現在要你做什麼？」；接著讓玩家找出選項成本、指出已發生/尚未發生與原因差別。
比較頁問「哪些條件固定、哪些不同？」；不問哪國比較好，也不提示標準答案。
記匿名年齡組、版本、展示順序、原話、操作卡點；不蒐集照片/聲音/姓名。
首次為探索，不預填通過率；收集後再定合格門檻與正式風格決策。
