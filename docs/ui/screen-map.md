# UI-01｜畫面地圖

目的：說清楚主流程與輔助流程的出口，避免只做頁面堆疊。

```text
事件首頁 ─ 選一項 ─→ 後果（已發生 / 尚未發生分開）
  │                       │ 查看原因          │ 直接繼續
  │                       ▼                   │
  │                    原因頁                 │
  │                       │ 比較環境          │
  │                       ▼                   │
  │                    比較頁 ─ 繼續 ─────────┤
  │                                           ▼
  └─ 人物 / 地圖 / 紀錄 → 關閉返回          下一事件
                                              │ 最後一個原型事件完成
                                              ▼
                                           原型回顧
```

事件頁沒有常駐大面積頁尾。後果/原因/比較採安全區內的 FooterActions；ScrollView 會讓出空間。
比較頁可回看同一個後果，不新增紀錄、不重抽結果。
原型回顧可以重新體驗；這是清除 Demo fixture 狀態，不是正式遊戲的改選或存檔功能。

不做：在沒有選擇後果時開放「下一年」；原型中跨事件的年齡/年份由下一筆 DTO 決定。
驗收：全部前進/返回路徑可走通，歷史只在有效選項確認後新增一次。
