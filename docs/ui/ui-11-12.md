## 實作契約與驗收

| 審查項目 | 本輪預期行為 | 驗證 |
|---|---|---|
| 頁首狀態 | 決策／後果／原因／比較／回顧各有狀態；回顧為「本段旅程完成」 | 完整原生流程斷言 |
| 比較配對 | 事件＋選項共同決定比較卡；查無或 key 不符顯空狀態 | 兩選項內容互斥、錯配 fixture |

## UI-12 固定示範腳本（獨立測試 oracle）

- 和朋友做簡易作品：阿澄「原來歪掉的地方，也可以一起修好。」；人際由「朋友願意支持」到「多了一次合作經驗」；能力由「動手探索中」到「找到紙橋要補強的位置」。下一事件帶入「那座一起重做的紙橋」與合作經驗。
- 先找老師想辦法：阿澄「還沒開始做，但我知道可以找誰幫忙了。」；人際到「找到可以求助的老師」；能力到「有了一張借用工具清單」。下一事件帶入「那張借用工具清單」；不顯示朋友合作的後續。
- 兩路保留 v1 的 2／1 格精力成本敘事，不新增數值、機率、分數或國家推算。前後標籤是編寫好的質性 fixture，不是假稱 Domain delta。
- 伏筆標「還沒發生」；下一事件只回提已發生的事，不把可能合作、借用或參展自動算成功。
- 角色表現使用已有場景＋台詞與符號，短淡入支援 Reduce Motion；沒有新增動物形象或正式表情素材。
- 下一事件與人物頁標示「上個岔路留下的狀態」；第二事件尚無新的完整狀態快照，不能把舊快照稱作最新引擎狀態。

## 人類 Gate 與移除條件

UI-12 本輪可交付的是可操作表現原型，不能宣稱已達「玩家能說出差異」。後續 UI-14 預先採 10～12、13～15 各組至少 5 人的形成性試玩；每組至少 4/5 能在無引導下說出一項已發生變化，且至少 4/5 能分辨伏筆尚未發生，作為建議門檻，**尚未執行或獲得玩家證據**。小樣本不代表統計成效。

UI-13 才由 Domain adapter 提供結果、完整狀態與真實 Trace，移除 fixture 的質性快照與旁白。實機與 VoiceOver 人工巡覽另待驗。這份有限原型不縮減 P1 完整人生目標。
