# UI-04｜首頁 v1

決策：事件卡主導，吸收章節敘事的簡短情緒節奏；人物總覽與時間軸移到輔助頁。
這是本輪實作方向，尚未取得 UI-10 的兒少驗證。

由上而下：

1. StageHeader：阿澄、13 歲、2027 年、青少年、事件位置、「等待你的選擇」、更多人生資料。
2. EventHeroCard：小型場景、事件標題、簡短問題。放大文字時省略裝飾插畫。
3. **你會怎麼做？**：明確進入決策。
4. 兩個可選 ChoiceCard，同等白底/深字/描邊；標示成本、支持與不確定性。
5. 第三個不可選示例以鎖與文字說明，不能只用淡色表達，也不能點了才知道不可用。
6. StatusStrip：健康、財務安全、人際關係、技能與能力；次要但可讀。
7. 人物/家庭與人生地圖入口；詳細紀錄在 sheet 與回顧頁。

相較前版：移除首頁風格切換、實驗室標頭、大段階段列與常駐比較/重設頁尾；縮小插畫；讓成本、支持/風險直接跟著選項。

狀態規則：

- 沒有事件：顯示沒有待選事件，沒有下一年按鈕。
- 沒有選項：留在岔路，不能替玩家決定。
- 不可選：顯示原因，Button disabled。
- 沒有後果：保留事件、說明缺資料，不新增歷史、不推進。
- 正常選擇：只顯示 fixture 提供的後果，再提供原因/比較/繼續入口。

樣式是結構驗證用：深色背景、等權重選項、低權重狀態。顏色不表示人生輸贏。
點擊區至少 44pt，主要選項至少 64pt 且隨內文增高，沒有文字 `lineLimit` 或縮字塞版。
所有頁首位於 ScrollView；操作列使用 safeAreaInset，避免覆蓋選項。

不做：從 UI 直接算剩餘資源或環境倍率。這版狀態文字與結果都是明示的設計 fixture。
驗收：Simulator 可操作與 screenshot 層級檢查；五秒辨識、是否像教材與吸引力，須人工另測。
