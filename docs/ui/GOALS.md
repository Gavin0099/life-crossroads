# UI-00｜重構目標

目的：讓玩家第一眼知道現在發生什麼、要選什麼、會付出什麼，完成選擇後看見故事推進。
先解決操作層級與節奏，再決定正式美術。

觀察基線為原 `VisualPreview`：頁首風格切換/階段、章節眉、大標題、插畫、敘述都出現在選項前；底部常駐比較與回到岔路。
這些資訊各有用途，但在第一次做選擇之前占用注意力。這是結構分析，不是玩家眼動或轉換率證據。

決策：首頁以事件卡與等權重選項為主；章節感只保留少量語氣；時間軸轉為輔助頁。
家庭、人物詳細狀態與紀錄不作首頁主視覺。簡化四項狀態置於選項之後，不合成人生總分。

成功標準：

- 產品假設：玩家五秒內辨識主動作、理解成本與選項差異、不把比較看成國家排行。
- UI 可檢查：標題/事件/選項層級清楚、選項大於 44pt 點擊區、小螢幕及大字可捲動閱讀、安全區不遮擋。
- 工程可檢查：事件到推進可走通；缺事件、選項、後果或原因有空狀態；不在 UI 推算結果。

不做：以截圖或 XCTest 宣稱五秒理解、兒少吸引力、教育效果或正式美術通過。
驗收：以上三組證據分開列，不用工程 PASS 代替人類可用性測試。
