# UI-01｜資訊架構與責任

目的：讓首頁回答「現在要做什麼」，輔助頁回答「我從哪裡來、走過什麼」。

| 資訊 | 處理 | 放置與原因 |
|---|---|---|
| 角色名、年齡、年份、階段 | 保留且精簡 | 頂部 StageHeader，定位現在 |
| 風格 A/B 選擇器、英文實驗室標頭 | 移出遊戲首頁 | 研究檔/Preview；不占遊玩動作 |
| 插圖、章節眉 | 降權 | 插圖縮小；大字級隱藏裝飾圖，事件描述完整保留 |
| 事件、兩到三選項、成本 | 主畫面保留並加權 | 主視覺；選項同權，不暗示道德標準答案 |
| 支持與不確定性 | 保留 | 每張 ChoiceCard 直接寫明 |
| 四項資源 | 降權 | 選項後 StatusStrip，質性狀態不作成功總分 |
| 家庭、家人與生活 | 次頁 | 人物/家庭 sheet |
| 同齡人 | 延後 | 待引擎有合格比較資料；不假造平均同齡人 |
| 人生地圖 | 次頁 | 五階段地圖，標目前位置 |
| 詳細年度紀錄、回顧 | 次頁/回合結束 | 只列實際選擇與提供的後果 |
| 原因 | 決策後獨立頁 | 與已發生後果分開；缺資料不補推測 |
| 環境比較 | 決策後輔助頁 | 固定/變動條件 + 上下家庭卡，不國家排名 |
| 分岔重算、完整晚年 | 延後整合 | 需要正式版本化引擎與原局保存契約 |

主流程：事件 → 後果 → 原因 → 比較 → 下一事件；後果/原因可直接繼續，避免每回合強迫閱讀。
輔助流程：事件 → 人物/地圖/紀錄 → 關閉 → 回原本岔路，不能因此提交選擇或改結果。
驗收：每個畫面有單一主要工作；進度不因打開輔助頁而改變。
