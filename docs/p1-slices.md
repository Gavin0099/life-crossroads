# P1：八國完整人生可玩版 — 開發切片

日期：2026-10-23。狀態：依使用者明確決策更新的開發路線；本輪尚未實作產品程式。
本版取代先前「科學展短篇獨立產品 Gate」；科學展可成為事件，但不再是範圍收縮條件。

## P1 目標與完成標準

| 項目 | P1 驗收目標 |
| --- | --- |
| 國家 | 8 個經來源、可比性及情境檢查的真實國家 |
| 家庭 | 每國至少 2 種，共 16 種家庭與成長情境 |
| 事件 | 50～70 個可觸發原創人生事件；地區變體不重複計數 |
| 一局 | 五階段完整人生，約 10～15 分鐘，12～18 個重要決策 |
| 跨國比較 | 至少 3 組關鍵選擇可產生清楚且可追溯的環境差異 |
| 長期後果 | 至少 3 組跨回合故事呼應，含實際排程/觸發 trace |
| 分岔 | 可回到一項重大選擇，保留原人生並比較另一條路 |
| 恢復 | 離線存續玩與同版本重播一致 |
| 玩家 | 10～15 歲試玩，同時觀察娛樂性、代價理解與環境理解 |

上述均為提高後的目標，尚未完成資料、內容或玩家驗證。
首批候選：台灣、日本、美國、德國、印度、巴西、越南、肯亞。
國家不足時須保留缺口並說明替換建議，不能默默把八國降為四國或把候選旗幟算成支援。
台灣可能使用另外的官方統計；定義、年份及母體須與其他來源逐欄比較。

## 第一個可玩交付

LC-02 即提供四國完整人生：
建立人生 → 童年 → 青少年 → 青年 → 中年 → 晚年回顧 → 再玩。
每局以關鍵事件和時間跳躍構成，具有 12～18 次重要選擇。
四國只是可交付的中途版本，整個 P1 仍需八國。

| 階段 | 共同故事責任 |
| --- | --- |
| 童年 | 家庭、居住與教育資源、興趣探索 |
| 青少年 | 學習、人際、挫折與時間分配 |
| 青年 | 工作、居住、獨立與繼續學習 |
| 中年 | 家庭、工作轉折、健康與照顧責任 |
| 晚年 | 重要人物、選擇回顧、傳承與不同可能 |

採共通事件系統＋環境參數＋家庭條件＋地區情境變體。
不寫八套獨立人生，也不把完整人生省略成單一場景。

## 模型與解釋契約

- `CountryProfile` 保存來源指標、年份/單位及資料版本；國名是識別，不是成功倍率。
- `HouseholdProfile` 分開保存家庭、城鄉、時間、照顧責任、設備及支持；16 個情境是透明設計的示範，不宣稱人口代表性。
- `DecisionResolver` 讀取明確環境條件與可行選項，分開計算選擇、環境、他人支持及隨機性。
- `ConsequenceTrace` 與結果同時產生，含前後值、成本、規則、資料/假設 ID、延遲鏈與實際抽樣。
- 「為什麼」只投影實際 trace；不由 AI 編因果，不產生無依據的原因貢獻百分比。
- 固定環境/家庭/選擇/Seed，只換國名時，數值結果相同；同國不同家庭也需有可解釋差異。
- 未觸發、clamp、不可行選項與支持路徑都記錄，不把失敗一律歸咎玩家。
- 國家平均不直接推出家庭聯合分布或個人選擇效果，映射及效果係數屬有版本的設計假設。

## 兩種比較

| 模式 | 固定與變動 | 邊界 |
| --- | --- | --- |
| 同選擇跨國 | 固定可比意圖、事件語意與配對機會；變動明列的環境/家庭條件 | 比較成本、支持與路線，不排行國家 |
| 同背景改選 | 固定背景、版本、分岔前歷史與外生亂數鍵；改一項重大決策 | 保留原人生，明列後續策略代選或新增選擇 |

相同家庭百分位不等於相同物質條件；同選擇不要求成本或可行性相同。
不可行的選項需顯示原因與替代途徑，不能直接算作角色失敗。
亂數以 Seed、子系統、事件語意 ID、年齡及 occurrence 編號穩定取值，避免路線多抽一次造成全局錯位。
後續相同且仍可行的選項照紀錄重播；新事件或失效選項以明定共同策略處理並標示。
這是模型內的比較，不是現實因果證明。

## 七個 slices

| Slice | 交付 | 核心驗收 |
| --- | --- | --- |
| LC-01 | 八國模型、16 情境、共通人生規則 | 可機讀區分資料/推估/假設，八國狀態透明 |
| LC-02 | 四國完整人生可玩版 | 首個可玩版即有五階段、12～18 決策及回顧 |

每片可作獨立 Issue/PR。以下路徑為預計範圍，開始時依實際 Swift package / Xcode 結構確認。

## LC-01：八國資料、家庭與共通規則

**DONE：** 建立可載入八個候選國家及 16 個家庭情境的模型、來源狀態矩陣與純 Swift 驗證；
先準備可供 LC-02 使用的四國完整資料包，其餘候選的缺口有明確狀態與處理方式。
八國全部來源可用仍是 LC-03 及整個 P1 的要求，不能以示範值冒充完成。

- `CountryProfile`、`HouseholdProfile`、`LifeState`、決策/trace 契約、五階段與共通資源規則。
- 八國逐欄核對來源網址、定義、母體、年份、單位、授權、缺值、公式及版本。
- 優先同年同義資料；不同年或不同來源需有可接受理由。缺值不是 0。
- 國家資料只支持合理環境；家庭情境、選擇效果與支持機制以設計假設另標。
- 電力取得不等於可靠供電，人口網路使用率不等於孩子持有設備；教育指標須核對年份及覆蓋。
- 16 情境不全部排成富/窮二分；各國都有條件差異、限制與支持。
- 固定 LC-02 四國名單、12～18 決策骨架、敏感內容及晚年回顧方式。
- 交付：Package.swift、Domain/Data 模型、Resources/Statistics JSON、來源/情境矩陣、Tests、純 Swift CI。
- 證據：Codable、錯誤單位/缺來源/缺授權/缺值拒絕、版本識別、只換國名不改結果。
- 排除：大量美術、後端及把資料整理當成已驗證遊戲性。

## LC-02：四國完整人生

**DONE：** 四個已備妥國家、每國至少兩家庭可在 iPhone 從童年玩到晚年回顧，
單局有 12～18 個重要決策，基本目標為 10～15 分鐘；Seed+決策可於純 Swift 重播。

- 建立原生 App、首頁/背景、五階段推進、共通事件、資源、決策與結局時間軸。
- 最小共通事件庫須足以支撐整局 12～18 決策；最終 50～70 內容量於 LC-05 達成。
- 各國環境及家庭實際影響成本、可行選項、支持或路線，不只更換旗幟。
- 立即結果、基本延遲排程與 ConsequenceTrace 從此片一起實作，供 LC-03 真實解釋使用。
- 即使低資源仍有調整、休息或求助路線；不設唯一成功人生總分。
- 共通角色或重要人物在後續人生呼應，讓選擇不只改數值。
- 放大文字、VoiceOver label、非僅靠顏色及略過敏感內容從第一個 UI 版本加入。
- 交付：App/Features、SimulationEngine、EventEngine、DecisionResolver、RandomSource、ConsequenceTrace、最小事件庫、Xcode project。
- 證據：四國八背景都能結局、五階段合法、資源/時間界線、延遲不重複、trace 一致、固定 Seed。
- Simulator 與實機分開記錄；首次完整人生可以測試，但不能把四國交付標成 P1 全部通過。

## LC-03：八國與跨國同選擇

**DONE：** 八國 16 情境可完整遊玩；至少三組共通關鍵選擇可並列比較成本、限制、
支持及後續路線，每一項差異可追到 trace 與來源/假設。

- 完成其餘四國來源與內容核對，不以旗幟/名稱或未標資料包湊足數量。
- 相同意圖使用可比 scenario/choice ID；明列比較時固定及變動的家庭條件。
- 支援同國兩家庭比較，避免所有差異被讀成國籍造成。
- 不排行國家；不可行選項具有原因與替代路線；配對機會不強迫互斥事件都發生。
- 交付：其餘資料包/地區變體、BranchComparisonEngine 的跨國模式、Comparison UI、三組比較證據。
- 證據：只換標籤不改結果、同國差異、缺資料不可比、條件不符、固定亂數重播。

## LC-04：長期後果與回到岔路

**DONE：** 完整化每個重要決策的後果追蹤與延遲鏈，可回到一項重大選擇改選，
保留原人生、分岔點前歷史及版本，清楚解釋兩條路差異。

- 在 LC-02 基本 trace/排程上完成串聯、失效、互斥、取消與支持事件，至少三組跨回合呼應。
- 快照包含 state、決策紀錄、待觸發後果、亂數識別及引擎/資料/內容版本。
- 後續共用策略代選須標示；玩家新增自由選擇後不再宣稱只改一項。
- 比較資源歷程、故事節點與原因，沒有總分或因果貢獻百分比。
- 交付：LifeSnapshot、完整 BranchComparisonEngine、trace/queue 規則、Timeline/Comparison UI、Tests。
- 證據：原路重播相同、歷史不變、不覆寫原局、延遲恰觸發一次、亂數對齊、版本不相容拒絕。

## LC-05：50～70 個事件與重玩變化

**DONE：** 有 50～70 個可觸發原創人生事件，支撐五階段與八國 16 情境的路線變化；
各局維持 12～18 個重要決策與完整人生，所有背景都可到達回顧。

- 事件可包含決策、支持、環境與延遲後果；「事件總量」與「一局決策數」分開驗證。
- 同一事件的八國文案/參數變體計為一個；純換名或只增 ID 不增加內容計數。
- 每事件有語意 ID、年齡/條件、選項或後果、來源/假設、敏感標記及 trace 引用。
- 逐背景檢查事件可達性；失效/永不觸發內容不算已交付事件。
- 至少三組跨國比較與三組長期呼應持續成立；不靠塞更多閱讀頁湊 10～15 分鐘。
- 交付：EventCatalog、Events JSON、變體、內容覆蓋與去重報告、批次模擬。
- 證據：各階段/背景可達、引用完整、無卡死、合法時序/數值、固定 Seed 批次不當機。
- 玩家回饋可在四國交付後即開始；不等到全部事件完成才發現核心體驗問題。

## LC-06：離線存檔、重播與原生體驗

**DONE：** SwiftData 存續玩與未中斷人生具有一致 state、trace、決策與後果佇列；
重播/分岔版本可辨識，完整人生的小螢幕及無障礙操作可用。

- SwiftData 限於 Persistence adapter，Domain 不依賴資料庫或 UI。
- 保存引擎/資料/內容/save schema 版本；損壞或不相容時保留原資料並提供可理解選項。
- 原局與分岔不互相覆寫；最小範圍為一局進行中人生及必要快照。
- 優化直向單手操作、文字量、回饋、五階段轉場與原因說明。
- 交付：SaveRepository、Home/Timeline/Comparison/Ending UI 修正、存檔與 UI 測試。
- 證據：round trip、延遲事件中斷恢復、損壞/不相容版本、離線、VoiceOver、放大文字/減少動態效果。

## LC-07：兒少與實機驗收

**DONE：** 完成 8～10 位方向性試玩，分別記錄 10～12 與 13～15 歲的操作、娛樂及理解，
並具真實 iPhone 證據，據此作 P1 可前進/需調整/需補證據的決定。

- 首次四國完整人生即可試玩；這片是最終彙整驗收，不禁止較早取得玩家回饋。
- 孩子自願、家長知情；不新增 app 內個資蒐集、分析 SDK、社群或付費誘因。
- 觀察是否自發探索另一背景或改選，以及能否用自己的話描述取捨、環境、支持與運氣。
- 使用實際故事回顧，避免誘導問題；檢查國籍決定命運、努力必勝、休息必輸等誤解。
- 小樣本不宣稱市場代表性、教育效果已被科學證明或適合低於首測年齡的兒童。
- 真實 iPhone、小螢幕、無障礙、內容略過、10～15 分鐘及工程 Gate 逐項留證。
- 交付：playtests、實機記錄、P1 acceptance 與必要內容/UI 修正、回歸測試。

## 治理與工期邊界

- 未驗證的完整 runtime 治理不阻擋 LC-01 或遊戲開發；其狀態繼續如實揭露。
- 基本 CI 的來源/版本/格式檢查與後續 Swift/遊戲正確性測試仍需通過。
- runtime 稽核在 CI 採 advisory，不因此宣稱實際平台治理已驗證。
- 此次範圍提高，原先 16～26 個有效工作天不作新版承諾；估算依資料及內容實際準備程度更新。
- 不擴充後端、帳號、即時 AI 劇情、全球完整模擬、大型美術、社群、排行榜、廣告或內購。
