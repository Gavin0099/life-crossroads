## 試玩

在 Xcode 開啟 `LifeCrossroads.xcodeproj`，使用 LifeCrossroads scheme。開新人生後，沐沐從日常生活片段走向下一事件；正常一段約8秒，3倍約2.75秒，也可暫停或直接跳到事件。事件到達便停住，等待玩家決定。保存成功後，同一河畔留下本次選擇日記與實際故事物件，再按「回到生活」。

固定測試起點：日本／家庭一／Seed 0。8歲投入興趣，會留下那次選擇的日記；10歲選擇求助，實際友情約定才會留下聯絡記號及阿禾互動。換成休息會留下自己的步調，不假裝已建立友情。13歲創作桌的詳細紀錄仍可展開，回顧、跨國/家庭比較、回到岔路與完整後半生比較保留。

按首頁、開啟說明或切到背景會暫停。回到前景需自己繼續；重新啟動則停在已保存的事件/結果，動畫位置不保存。沒有離線成長或背景自動選擇。所有播放控制都不改事件亂數、人物關係或資源。

## 兩個開發角色

- Gameplay：`LifePlayback`、`LifeWorldViewState`、GameStore、CrossroadsView、保存邊界與正式整合。
- Visual World：獨立 `LifeWorldScene(state:)`，原創 SwiftUI 分層河畔、水獺、待機/行走/互動、日/晚光線與故事物件；只消費契約，不接觸引擎。

[共用契約](life-world-contract.md)與 [ADR 0006](adr/0006-presentation-life-loop.md)說明恢復語意和畫面來源。河畔是共用虛構舞台，物件是執行紀錄的象徵，不是國家實景、獲獎證明或未來保證。沒有匯入未核准 Visual WIP 或參考作品素材。

## 驗收界線

純 Swift 測試覆蓋播放邊界、真實兩事件故事來源、完整15決策在不同播放方式下的 trace/選取不變、實際磁碟存讀。這種隔離測試不能單獨證明 App 接線，因此另以原生 UI 驗證自然到達、暫停/加速/跳過、背景與重開、真實檔案 SHA、寫入失敗後世界/檔案不變及重試，並回歸完整人生與分岔。

本片不宣稱真人10～15分鐘節奏、兒少喜好、實機、人工 VoiceOver 或完整資料授權 Gate 通過。場景仍是可測試的程式原型；正式選稿與各國情境可在此契約上獨立推進。
