# 紙橋工坊：13→15歲持續生活切片

此候選回應2026-10-24的產品修正：先證明行動能留下可玩的未來差異，再增加演出。從main `5701a36`建立`codex/sim-workshop-continuity`，不將舊Visual原型的示範規則帶入Domain。

## 玩家能做什麼

留在同一間工坊，免費觀察材料及夥伴，再安排一個有成本的行動。採取行動後工作桌、人際熟悉度、資源及人生紀錄同步更新，離開或關閉App後仍保存。13歲的經驗成為15歲事件的資格條件。插圖開關只改變呈現，不改變任何人生資料。

原生試玩固定日本第一家庭、Seed 42，讓兩路能從同一起點比較；此頁沒有跨國選擇器。Domain回歸另外覆蓋四國與兩家庭。重開同起點不是改抽一個較有利的出生；工坊也沒有與LC-04未合併的人生分岔功能混用。

|13歲行動|持續記錄|15歲額外可操作行動|
|---|---|---|
|和阿禾一起試作|試作事實、阿禾熟悉度+2、實際技能效果|試作事實＋技能至少24＋阿禾熟悉度至少2：陪同帶領|
|向樹老師求助|準備清單、老師熟悉度+2、實際技能效果|準備事實＋老師熟悉度至少2：核對借用工具|
|先休息|暫停紀錄，既有經驗不因休息消失|仍可練習、詢問及休息|

門檻及熟悉度是遊戲設計假設，並非真實教育或工具借用機率。兩條路沒有唯一較好的答案。核對清單不等於工具已借到，試作不等於紙橋已完成。

## 同一個引擎

`WorkshopCatalog`重用原資料與家庭，載入原創兩事件內容；`LifeSession`、`DecisionResolver`、`StoryBranchEngine`、`StoryMemory`、`KeyedRandom`與`ConsequenceTrace`負責全部遊戲規則。UI只發送行動及呈現實際結果。未開放的行動即使偽造ID也不能執行；載入時完整重播並拒絕偽造的歷史、版本或排程。

`DecisionTimeline`將這個試玩隔離為`workshop-13-15-v1`內容版本。原完整人生仍有8～80歲的15個決策，未被兩事件試玩取代。原`catalog.json`及國家統計未改動。年齡從13跳到15；沒有模擬中間每一年，也沒有捏造14歲經歷。此切片不代表P1八國完整人生完成。

工坊使用獨立的本機Application Support存檔。先驗證、原子寫入成功，再套用畫面狀態；載入損壞時保留原檔並顯示錯誤，只有玩家明確重新開始才取代。沒有新增網路、帳號或分析服務。

## 後續整合

- LC-04分岔／保存：先與其尚未合併的LifeSession／Persistence變更做API與內容版本審查，保留原人生與分岔各自的timeline。不能直接搬入此試玩的單檔存檔當作正式分岔系統。舊排程解碼、完整重播及跨版本拒絕需保留回歸。
- LC-03八國：仍由原StatisticsRepository提供來源檢查與家庭；新增國家必須先通過原資料Gate。本故事沒有新增各國倍率，也不能將四國測試當作八國已支援。
- LC-05量測：完整人生的批次基線仍採原15決策；本試玩192條條件回歸是另一個樣本，不能混入原1,024局指標。正式採用15歲節點或擴充到第三事件前，先決定完整人生節奏及內容版本，再重跑完整局與可達性量測。
- 選稿與遊戲感：先review現有兩路的可觀察取捨並依SIM-04真人結果修正機制，再擴充事件。候選圖不因自動測試通過而自動獲正式核准。

## SIM-04真人試玩預先標準（尚未執行）

分10～12及13～15歲，每組至少5位；由合適的成人安排試玩，不收集可識別個資。每人先自由玩一條路，再從同起點嘗試另一條路；一半先關插圖以降低演出干擾。順序交錯，記錄原始分母與缺失資料，不將小樣本推論為整體兒少結論。

- 每組至少4/5無提示完成觀察、行動、前進與15歲後續行動。
- 每組至少4/5能指出13歲行動如何影響15歲的機會，而不只複述旁白。
- 每組至少3/5在研究者邀請前主動表示或操作繼續／重試；記錄時間及原話，不將按下受指示的按鈕算作動機。
- 每組至少4/5知道休息及求助仍是可行選擇，沒有把技能門檻理解成人生價值分數。
- 分別記錄是否在意角色、預測下一步、探索原因；同時記錄困惑與放棄。實機、人工VoiceOver及真人喜好各自驗收。

任何組別未達標即保留為待改進候選；工程測試或AI Critic不能替代以上證據。先檢查是否缺少可理解的機會與取捨，再決定是否擴充事件。
