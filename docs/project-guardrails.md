# 《人生岔路》專案執行規則

依據：使用者提供的 v0.1 計畫、兒少受眾補充及 2026-10-23 平行世界人生實驗目標。
本文件補充框架，不改寫框架的受保護文件或驗證語意。

## 產品與內容

- 核心受眾 10～15 歲，娛樂性與啟發性並重；未測年齡不自動納入已驗證範圍。
- P1 為八國、16 種家庭情境、50～70 事件；每局五階段完整人生、12～18 決策、約 10～15 分鐘。
- 首個可玩交付為四國完整人生，後續擴至八國；科學展不再是獨立產品 Gate。
- 核心體驗：環境影響機會、選擇影響結果，人生不完全由自己控制。
- 使用國家 × 家庭環境 × 選擇 × 隨機事件，並呈現他人支持；禁止國籍成功倍率。
- 不是每個選擇都有正解；不把好的選擇保證為好結果，失敗後保留調整及求助路線。
- 國籍、性別、家庭條件、疾病及貧窮不得等同角色的道德價值。
- 不以資源高低合成單一人生成功分數；要有孩子能理解的選擇代價與故事回饋。
- 敏感內容須有適齡規格、提示與略過路徑，不描繪傷害方法或寫實暴力。
- 第一版離線、無帳號、無廣告、無內購；新增蒐集資料或連網功能視為範圍變更。

## 模擬與資料

- 核心引擎純 Swift；UI、存取、時鐘與亂數來源透過明確邊界注入。
- 固定 Seed 重播須保存決策紀錄、引擎版本及資料/內容版本。
- 同背景重玩、完全重播、改選一項決策、跨國同選擇比較分開定義及測試。
- ConsequenceTrace 記錄實際計算依據；說明只能由 trace 組成，禁止 AI 編造因果。
- 不用平均壽命作為每個角色的預定死亡年齡。
- 每個正式資料欄位保留來源網址、年份、地區、單位、授權、缺值處理、公式及版本。
- 統計分布、推估與設計假設分開；國家平均不能直接當成個人因果機率。
- P1 候選為台灣、日本、美國、德國、印度、巴西、越南、肯亞，每國至少兩種家庭情境。
- 國家須通過可比資料與內容檢查才算可用；台灣官方來源另行核對，候選不等於已支援。
- 共通事件搭配環境、家庭與地區變體；同一事件的國家變體不重複計入 50～70 總量。
- 參考作品僅供比較；不得把其事件、程式或素材抓取為本專案內容庫。

## 驗證與交付

- 每片先定驗收再開發；P1 內完成 50～70 個原創事件，保持四國完整人生先交付、八國最終驗收。
- P1 不擴充大型美術、後端、社群或排行榜；玩家回饋從完整人生首交付即可開始。
- 核心規則測 Seed 重現、時序、數值界線、可推進性、延遲後果及 trace 一致性。
- 存檔測 round trip、損壞資料及版本不相容，不以重新開始掩蓋資料遺失。
- UI 驗證含小螢幕、放大文字、VoiceOver、非僅靠顏色的提示及敏感內容略過。
- Simulator、實機、兒少試玩、TestFlight、App Store 各自列證據，不能互相替代。
- 一個開發階段對應獨立 Issue 或 PR；各片以新版 docs/p1-slices.md 為範圍。
- 2026-10-23 使用者授權公開前檢查、push、LC-01 實作與必要提交/切片 PR；未授權 App Store 發布。
- 基本 CI 與遊戲正確性測試維持必要驗證；未驗證 runtime 治理不是產品開發前置 Gate。
- CI 的完整 runtime 稽核採 advisory，保留原始錯誤與未驗證狀態。

## 風險設定的意義

domain 直接依使用者規格設定。`risk_tier: medium` 是助理為本次可逆導入工作設定的
執行姿態，不代表負責人已簽核整個產品的風險分類。核心模擬、存檔及兒少內容依 AGENTS.md 升級。
框架 onboarding SOP 的人工 domain/risk 確認另列待驗收，不以工具通過取代。
