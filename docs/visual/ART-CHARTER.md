# 美術準則

目標：10～15 歲能辨識選擇、代價、後果與環境；用故事冒險感邀請探索。
以下是設計假設，尚未由兒少試玩驗證。

1. 角色採原創擬人動物；每個角色均可出現在八國，物種不對應國籍、天賦、人格或壽命。
2. 五階段是人類人生的比喻。晚年保留尊嚴與能動性，不以疾病當必備辨識記號。
3. 角色與背景只傳達情境，真實原因與數字由引擎 View DTO 提供。缺少 Trace 顯示「沒有原因紀錄」。
4. 困難有求助與調整路徑；沒有國家排行、道德紅綠燈或人生總分。
5. 原生 SwiftUI 繪製中文字、成本、按鈕；插畫不含文字。角色圖不使用真實兒少照片。
6. 不使用現有遊戲角色、特殊版面或藝術家風格作模仿指令。
7. 候選與正式素材分開。未核定工具條款、輸入權利與人工選稿，不能轉入正式 App。

採用方向：先用內建 ImageGen + 角色參照 + 版本化 prompt；不安裝本地模型。
編修備案為 Krita；大量生產才評估 ComfyUI。rembg 的預設模型不得因套件 MIT 就視為可商用。

升級決策：重大授權不確定、角色改成人類、改變遊戲方向、開始付費 API/模型下載前才提出選項。
本輪沒有啟用第三方付費 API、下載模型或新增 App 網路行為。
