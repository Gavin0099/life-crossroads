## 非誘導試玩表（待執行）

兩組分開：10～12、13～15；自願、家長知情、不留姓名照片聲音與可識別資料。
每組交替先看 A/B，使用相同故事；記匿名 session 編號、畫面版本、年齡組與先看順序。

1. 「你覺得這裡正在發生什麼？」記原話，不先解釋。
2. 「如果你要選一個做法，你會按哪裡？會花掉什麼？」記是否找到成本與支持。
3. 「這個結果有哪些原因？哪些還不知道？」觀察是否把示範原因誤認真實證據。
4. 「兩個環境有什麼相同或不同？」不問哪個國家比較好。
5. 「這五張是同一個角色嗎？你怎麼判斷年齡？」記辨識錯誤與信心。
6. 「哪個畫面讓你想繼續？有哪裡看不懂或讓你不舒服？」不提示可愛/成熟答案。

人工藝術專家先驗表：角色比例/耳尾/服裝、年齡可辨識、IP 近似、文化語意、傷害內容、裁切與可讀性，各填觀察、問題、建議，不預填通過。
