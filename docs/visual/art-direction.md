# Art Direction Bible v0.1

範圍：候選比較，非正式選定。使用者追加貓與全部角色五階段，年齡圖暫採 A 統一驗證。

| 項目 | A 暖紙敘事 | B 靛夜冒險 |
|---|---|---|
| 材質 | 乾筆水粉、節制紙紋 | 乾淨輪廓、色塊與平塗陰影 |
| UI | 象牙紙、墨綠、暖木 | 深靛、薄荷、琥珀 |
| 情緒 | 安定、親近、有探索感 | 專注、有遊戲章節感 |
| 風險 | 可能被 13～15 歲視為繪本 | 深背景可能使生活題材較嚴肅 |
| 共通 | 同角色、同事件、同選項、同 viewport、同資訊順序 | 同左 |

事件固定為 13 歲社區科學創作展：紙橋、材料與時間有限、朋友合作或尋求老師支持。
它只是共通故事範例，不是被取消的「獨立科學展產品 Gate」。

設計建議：先保留 A 的敘事情緒，B 的層級可作另一候選；尚無專家或玩家選稿證據，不能宣稱 A 已勝出。
原型兩套方向都可點按，不能以換色或不同文案造成偏好混淆。

構圖：角色/道具位於畫面中段，文字獨立於插畫；耳、尾、手部不能被 UI 當成任意裁切區。
手機英雄圖是完整場景的預覽，正式輸出需另做直向安全區與裁切覆核。

一致性鎖定：先參照母圖，再改單一變因。A/B 輸出非像素重現；模型/seed 若未揭露填 null。
不得將「有一張相似圖」當五階段一致性通過；年齡表需逐格檢查標記、尾、服裝與比例。

反例：嬰兒大頭、絨毛玩具感、誇張邪惡窮人、強迫笑容、晚年必坐輪椅、按國家替換動物。
保留：情緒可複雜、困境不羞辱、失敗後仍能求助、沒有唯一正確選項。

尚待：人工藝術專家先驗覆核；10～12 與 13～15 分群偏好、情緒理解與可讀性測試。
