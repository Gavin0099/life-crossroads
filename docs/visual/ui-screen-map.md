# 九畫面規格與線框

線框圖：`assets/concepts/screen-map.svg`。只有下列標示互動的四狀態已實作，其他是 LV-05 待辦。

| 畫面 | 由上到下 | 原型狀態 | 驗收重點 |
|---|---|---|---|
| 首頁 | 標誌→人生邀請→開始/續玩→離線提示 | 線框 | 不先要求帳號 |
| 化身 | 四動物卡→外觀選取→確認 | 線框 | 國籍與能力不綁物種 |
| 背景 | 國家/家庭→可用支持/限制→來源/假設→開始 | 線框 | 不顯國家總分 |
| 人生地圖 | 五階段→已發生節點→目前岔路 | 線框，原型有階段列 | 五階段完整人生方向不縮減 |
| 事件 | 章節/年齡→角色場景→有限資源→兩選項/成本 | 互動 SwiftUI | 合作與求助皆可選 |
| 後果 | 已選項→立即變化→可能延遲→為什麼 | 互動 SwiftUI | 不承諾未觸發的延遲事件 |
| 為什麼 | 證據標示→實際因素→來源→無紀錄狀態 | 互動 SwiftUI | 缺 Trace 不編造原因 |
| 跨國比較 | 固定/變動條件→上下家庭卡→限制 | 互動 SwiftUI | 比較成本/支持，不排名 |
| 分岔/回顧 | 分岔前共用歷史→原路/改選→人物呼應→保存原局 | 線框 | 不顯虛構正式差值 |

本輪沒有加入人類角色對照圖；它仍是交接包的候選研究項，不影響使用者已指定動物與貓的交付。
實際主 App 的 UI 由 LC-02 工作線持有；此線以獨立 target 提供候選，不搬動或覆蓋其畫面。
