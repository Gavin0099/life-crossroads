# GS-01～03 視覺遊玩劇本契約

2026-10-23。來源為本輪使用者的「生活世界主畫面＋事件決策浮層」方向；本契約先於模型與測試撰寫。具體台詞、人物與演出節拍是這次原型的設計提案，並非已驗證的真實人生資料。

## 範圍與資料邊界

本片是可操作的演出原型。世界狀態由完整、明確標示的劇本快照提供；UI 不計算人生規則，不接 Domain、Persistence 或 ConsequenceTrace，不以單一選擇預言成年職業或人生成功。

- 主角阿澄，13 歲，2027 年，和朋友小禾在社區工坊製作紙橋。照顧者在場提供支持。
- 兩個選項為 `workshop-2027 + team`（一起重做）與 `workshop-2027 + help`（向老師求助）。只以選項 ID 查結果不符合契約。
- 四項資源固定為健康、財務安全、人際關係、技能與能力，均為質性文字。沒有自造分數、加減值或成功率。
- 原因及環境比較也是設計劇本，必須帶來源與限制文字；不呈現為正式 Trace，也不把情境示意稱為已驗證的跨國比較。

## 播放與錯誤契約

1. 等待玩家選擇時，手動推進、自動播放及 tick 都不會跳過決策。
2. 接受選擇後，立刻顯示本路線的當日下午快照，留在生活場景，並停止自動播放等待玩家看見反應。
3. 手動「下一刻」前進一個節拍。隔天後先進入時光過場，年軸從 2028 逐次到 2035，再進入 2036 成年重訪；過場快照維持回憶中的 13 歲，資源與關係不變，不新增紀錄。自動播放在正常速度每 3 次 tick 前進一次，快速每 1 次 tick 前進一次；tick 是演出訊號，不是人生時間計算。
4. 暫停時任意次 tick 不改變快照、年齡、年份或紀錄；開始播放或變更速度會重置未完成的 tick 計數。
5. 成年節拍再推進一次才到本段結束；結束時停止播放。之後 advance、tick 或播放要求均不新增內容。
6. 每個已播放快照只新增一筆紀錄。重複點選或重入結束狀態不可重複記錄或換掉既有選擇。
7. 重新開始清除選擇、紀錄、錯誤、速度與播放狀態，回到同一個初始條件，才能比較另一條路。
8. 不存在的選項、錯誤事件與選項配對、缺少路線、缺少下一節拍、重複節拍身分、缺少四資源或倒退的年齡／年份，都顯示資料錯誤並停止；保留最後有效場景，不補編、不跳過。重新開始可離開錯誤狀態。

## 驗證方式與限制

`tools/ui/check-world-flow.swift` 直接編譯實際模型。依上表斷言固定路線的物件、心聲、人物、年齡／年份與紀錄，另驗證 gate、暫停、速度、末尾、重選、重啟及失敗路徑。預期值來自本文件，不在測試中重寫狀態機。

原生場景佈局、觸控、文字縮放與畫面連續性另由 UI 測試和截圖驗證。這些證據不證明真人期待下一事件、在意角色或感受到路線差異；GS-04 仍需 10～12 與 13～15 歲分組試玩。正式引擎接線時移除這些示範快照，改由可追溯 DTO 供值，並保留缺漏拒絕行為。
