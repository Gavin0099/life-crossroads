# Visual Gameplay：驗收設計與真人試玩提案

本文件依據使用者 2026-10-23 的方向修正：生活世界是主畫面，Event-First 保留為事件決策浮層；角色、世界與選擇痕跡必須可見。以下是 **proposed 驗收方法**，不是使用者已批准的數值門檻，也不是測試執行結果。實際通過與失敗須另附本次版本、操作、截圖或測試紀錄。

本輪只驗證 GS-01～03 的有界視覺切片。編寫好的示範時間點與質性狀態可以驗證表現方式，但不能證明正式人生引擎、完整人生、跨國模型、兒少適齡或「已經更好玩」。四項資源仍為健康、財務安全、人際關係、技能與能力，不採用參考示意中的新數值模型。

## GS-01｜生活場景

要觀察的是玩家持續看見「阿澄在哪裡、和誰生活、目前在做什麼」。不能以放大一張靜態插畫、在下方繼續排列舊文字卡，取代這個目標。

| Proposed 檢查 | 操作與可觀察結果 | 必要證據 |
|---|---|---|
| 世界為主體 | 初次進入即能辨認主角、生活場所，以及家人或朋友；主角具完整可辨識的身形，不只頭像。姓名、年齡、時間與場景指向同一時間點。 | 正常與窄螢幕的原生首頁截圖；人工檢視角色、地面、人物之間的比例。 |
| 決策浮層 | 開啟事件時，場景仍在同一主畫面中；能收起浮層觀察世界，再開啟同一未選事件。兩個選項可辨識、可點擊，收起不代表已選或略過。 | 收起／展開前後截圖與 UI 操作結果；事件 ID、時間、紀錄不因收起而改變。 |
| 有生活人物 | 世界中可見人物與家庭／朋友入口內容一致；入口有實際內容與回到世界的方法，不是無作用裝飾。 | 可操作流程與人物身分對照。若場景只有朋友而家人只在資訊頁，需明列，不能宣稱家庭已在世界中演出。 |
| 世界不是報告背景 | 玩家做選擇後仍能看見同一場所與主角；不必先打開「原因」或「比較」才知道發生什麼。 | 從選前到反應的錄影或連續截圖；不能只提供結果頁孤立截圖。 |

## GS-02｜兩條路線先在世界裡產生回饋

同一事件在相同起點各走一次「與朋友合作」與「向老師求助」。這是原創示範敘事，不以任一路線較高分作為成功定義。

| Proposed 檢查 | 操作與可觀察結果 | 必要證據 |
|---|---|---|
| 角色先回應 | 選擇後，主角反應在原場景內呈現；繼續人生仍由玩家操作，不因短暫動畫結束而自動錯過反應。 | 兩路反應截圖；選項連點不造成重複紀錄或跳過反應。 |
| 路線的視覺差異 | 兩路至少有一項文字之外的可見差異，例如不同支持者出現、角色姿態或道具改變。只換標題、數字、顏色或 SF Symbol 不足以說明世界真的不同。 | 同尺寸並排畫面；指出差異在哪個人物或物件。 |
| 敘事事實一致 | 場景道具、角色對話、質性狀態與人生紀錄均來自該事件＋選項的同一份示範快照。尚未借到的工具不得先出現在手中；未確認的參展不算完成。 | 對照固定劇本／DTO；缺資料或錯配時不呈現另一條路線的結果。 |
| 狀態可理解 | 變化在選後可見，並能查到之前與現在的差別；未提供數值來源時不補算「+技能」或進度百分比。四項資源標籤與內容一致。 | 兩路狀態截圖與資料對照。 |
| 痕跡能留下 | 到下一時間點後，選過的人物支持、物件或回憶至少有一項仍可找到；紀錄只記已發生的事，伏筆明示尚未發生。 | 下一時間點與人生紀錄截圖；回看或關閉詳情不重複新增紀錄。 |
| 深入功能可選 | 原因、環境比較可開啟、關閉；關閉回到原世界與原時間點，不強迫依序看完報告才能繼續。 | 來回操作；時間、路線、紀錄不變。示範解釋不可標成正式 ConsequenceTrace。 |

## GS-03｜可控制的人生推進

不要求本輪補齊所有年齡或事件；要求玩家能看見已實作時間點之間的連續關係。若採離散的編寫時間點，應直接顯示時間跨度，不能用動畫暗示中間幾年已模擬完畢。

| Proposed 檢查 | 操作與可觀察結果 | 必要證據 |
|---|---|---|
| 時間有過程 | 選後留在世界，玩家操作繼續後，年齡／年份／生活片段一起推進；新片段仍能看見上一選擇留下的痕跡。 | 包含選擇、反應、推進與回提的連續操作證據。 |
| 推進可控制 | 暫停期間時間與故事紀錄不再前進。恢復、單步或加速若存在，按鈕語意與實際行為一致；不得越過尚待選擇的事件。 | 暫停前後快照、恢復後行為。若採播放控制，使用可控 tick 測試，避免只靠任意 sleep 推定正確。 |
| 看得見成長 | 至少一個已實作成年時間點換成一致的成年造型；年齡與外貌同時更新，身分仍可辨識。換衣服而年齡不變不能稱為成年演出。 | 青少年／成年同尺度對照；人物名稱、年齡、造型 ID 對照。 |
| 關係隨故事更新 | 人物頁與世界中的支持者能反映已走路線，不把所有未選可能性同時列為人生事實。 | 兩路在後續時間點的人物與紀錄對照。 |
| 人生紀錄與地圖可用 | 入口可開啟且可返回；已發生節點可辨認，未實作人生階段不能偽裝成已走過。重玩清空本次選擇，再走另一條路不留前次結果。 | 兩路重玩、空紀錄、已發生節點測試。 |
| 播放有邊界 | 開啟詳情、App 進入背景或切片結束時，時間不在背後跳過待看的片段。結尾明說本段已完成，沒有無作用的「下一步」。 | 背景／回前景、詳情、結尾的定向測試。 |

## 工程與可及性檢查提案

- **窄螢幕與最大字級**：最後一個選項、完整文字末行和主要操作均能捲動到可見範圍；場景與浮層不能遮住可點區。不能以元素 `exists` 取代完整 frame 可見及可點的證據。
- **減少動態效果**：關閉大幅位移或循環晃動後，仍能看到同一角色反應、狀態差異及時間跨度；不以動畫作為唯一訊息渠道。
- **VoiceOver 結構**：主角與重要變化有可理解的描述；背景裝飾不製造多餘焦點；選項含標題及必要代價；浮層展開與收起後焦點不丟失。原生可及性樹或 UI 測試只能驗證部分結構，實際朗讀與巡覽另列待驗。
- **錯誤與重複操作**：事件／路線／快照缺少或錯配時不編造結果；重複點擊、詳情往返、暫停恢復不多記一次選擇；時間不能倒退至未選路線，除非明確重新開始。
- **Simulator 清理**：每次測試建立專用暫存裝置，成功、失敗或可處理的中止均刪除本次裝置資料；原始測試包、截圖與必要錄影存於裝置外。刪除後以精確 UDID 確認已不存在，不刪其他任務裝置或共用 runtime。

## GS-04｜真人遊戲感驗收提案，尚未執行

目標是觀察玩家是否在意角色、期待下一件事，以及能否感到兩條人生路線不同。工程通過只能讓這次試玩可進行，不能替這三項問題作答。

**Proposed 招募與方式**：10～12 歲、13～15 歲分組，各先邀 5 人作探索性試玩；這個小樣本只用來找問題，不代表普遍偏好或教育效果。由負責人安排適當的監護人同意與孩子自願參與，可隨時退出。以匿名代號記錄操作及原話，不在 App 新增帳號、分析 SDK 或收集兒童個資。

**Proposed 順序**：每組交錯安排先走朋友路線或老師路線，減少第二次熟悉操作帶來的偏差。第一輪不預先教操作、不解釋哪個選擇較好；遇到阻塞才協助，並記錄協助點。完成一條路線後，讓玩家自然決定是否想繼續或看另一條路，再以中性提問了解原因。

| Proposed 觀察 | 中性提問或任務 | 記錄方式 |
|---|---|---|
| 主角存在感 | 「你現在在陪誰經歷什麼？」 | 玩家是否能指出主角、年齡／處境、生活人物；保留原話，不提示正確答案。 |
| 選擇造成不同 | 「剛才做完選擇，你看到什麼變了？」 | 分別記下自發指出的角色／世界／狀態／後續差異，以及誤認為已發生的伏筆。 |
| 在意角色 | 「如果繼續，你最想知道誰接下來會怎樣？為什麼？」 | 記錄是否提到主角或關係人物、理由；不把禮貌說喜歡當成投入證據。 |
| 期待下一件事 | 切片結尾先讓玩家選擇結束、回看或重玩；再問選擇原因。 | 記錄自發繼續／重玩意願、停留與離開原因；時間長短不單獨當成好玩。 |
| 兩路差異 | 體驗第二路後問「你會怎麼向朋友介紹這兩次的不同？」 | 能否說出至少一項畫面或人物差異及一項故事痕跡；若只記得不同文案，列為需調整。 |
| 控制感 | 「先停在這裡看看周圍，再讓故事往下一段走。」 | 是否能收起事件、暫停或單步並恢復；是否誤以為關閉浮層是略過。 |

**Proposed 決策方法，非已批准 Gate**：先分組逐項回報完成／需協助／未完成的實際人數與例子，不合併成一個「遊戲感分數」。理解錯誤、操作阻塞與缺乏興趣分開判斷。若要採用例如「每組至少 4／5 人無協助完成核心流程」的門檻，應在招募前由負責人決定並固定；本文件不替負責人批准門檻，試玩後也不能為了通過改定義。

## 實機與 VoiceOver 提案，尚未執行

在實體 iPhone 上各完成兩路一次，記錄機型、iOS、字級、減少動態效果設定與版本。觀察角色清楚度、浮層觸控、滑動、發熱與畫面切換；Simulator 截圖不代替這些觀察。

VoiceOver 巡覽至少涵蓋：進入世界 → 找到主角與時間 → 開事件 → 聽完兩個選項 → 選擇 → 聽到反應與變化 → 關閉／重開詳情 → 人生推進 → 找到成年造型描述與紀錄 → 回到世界。記錄焦點順序、重複朗讀、被遮住的焦點、無法返回及動畫中斷。修復後重跑同一路徑；有條件時邀請熟悉 VoiceOver 的使用者參與，代理的靜態標籤檢查不能稱為真人可及性驗收。

## 尚不能宣告的結論

未有相應證據前，GS-04 真人吸引力、年齡適合度、實機體驗、VoiceOver 實際巡覽均維持未驗證。此次有界切片不代表正式引擎接線完成、八國完整人生完成、素材獲正式採用、可合併全部堆疊分支或可發布。
