# LX-04｜不同出生、不同人生

基底：PR #12 `3f6cbfb`。2026-10-27 使用者覆審：CONDITIONAL ACCEPT、Draft/HOLD。PR #12 CI attempt 2 已成功，attempt 1 的漏接點擊仍未確認根因。這是完整八國人生中的體驗切片，不另設短篇產品 Gate。

## 範圍與先定驗收

1. **出生**：主要入口等機會抽選目前可玩的 16 個虛構家庭情境，明示八國示範、不是全球出生機率。獨立亂數鍵、版本、候選及選中背景可追溯；同 Seed 不受候選排列影響。手選保留在探索模式。保存成功才進入人生，恢復不重抽。
2. **處境**：角色場景恢復首屏；家庭條件及真正執行的環境規則呈現創作願望的限制與支持。國家平均不是個人實況；缺資料如實標示。離線創作不假造網路成本；成本一樣就說一樣。
3. **後果**：使用現有 13→17 歲故事事實、人物與實際邀請，不把尚未發生的線索寫成成功。數值留在可展開的依據，故事在前。
4. **平行人生**：完成原局後，以同 Seed、另一個出身重新親玩全部 15 次決策；保留原局，完整存讀與逐段故事比較。不同出生與後續選擇共同參與差異，不宣稱單一變因因果。
