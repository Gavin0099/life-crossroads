# RNG-01～04 驗證契約

本文件先於新增測試與批次程式建立。預期值來自使用者要求、現有完整人生契約與下列不變量，不在測試中重寫抽選演算法。

## 範圍與測試資料

- 既有 15 個人生節點作為 15 個決策槽，涵蓋童年、青少年、青年、中年、晚年；新增少量原創事件與既有節點競爭，不增加每局決策數。
- 主批次：日本、美國、印度、肯亞 × 兩種既有虛構家庭 × Seed 0～127，共 1,024 段完整人生。這是工程抽樣，不是人口發生率。
- 決策策略使用獨立語意鍵決定可行行動；輸入策略與 Seed 保留在證據中。不得因抽選失敗而偷偷改回固定劇情。
- 事件權重、年齡窗、資源與關係門檻都是明示的遊戲設計假設，不是國家或兒少的現實機率。

## 必須成立的不變量

1. 年齡、國家環境數值、家庭、資源、關係與歷史條件不符者不可入選；錯誤設定（空 ID、重複 ID、非法權重／門檻）需拒絕。
2. 固定 Seed、資料版本與相同決策序列，入選事件、實際後果、長期事實與最後狀態相同。
3. 候選清單反序仍得到相同事件與 trace；不得依陣列第一個符合條件者決定結果。
4. 一次性事件最多一次；可重複事件僅在冷卻完整經過後可再入選；互斥事件不得在同一人生同時發生。
5. 每個重要決策均有入選 trace 與實際執行 ConsequenceTrace；被拒選項不改狀態、也不產生事實或後果。
6. 以穩定事件 ID／選項 ID／發生次數區分重複事件；選項文案更名不影響規則。
7. 早期選項留下的有來源事實，真正改變後續事件資格或可行選項；同 Seed 改選可看出可核對差異。
8. 四國兩家庭均能經過五階段、完成 12～18 個決策、走至 80 歲回顧；80 歲是敘事收束，不是死亡年齡。
9. 每個事件保留無材料求助與免費休息；極低長期資源和零材料亦有可完成路線。兒童不能被迫承擔成人責任。
10. 中途存檔編解碼後與不中斷人生一致；不符版本與遭竄改的歷史需拒絕，而非自動重新開始。

## 抽樣與可達性分開報告

每個定義記錄 eligible（符合條件次數）、selected（入選次數）、resolved（成功選擇次數），同時保留零次事件清單與測試上下文。eligible 不是人生數，trigger rate 的分母必須明列。

狹窄條件若在主批次未出現，不可因大量人生皆完成就宣稱可達。另以具名 targeted fixture，從合法起點與可重播選擇建立所需歷史，證明一條實際可達路徑；人工製造不可能狀態只能作邊界測試，不能當內容可達性證據。

權重抽選以獨立的 1:3 固定候選測試作寬容統計檢查，並檢查兩者皆能入選。這只可偵測嚴重權重失效，不證明隨機品質或教育／遊戲平衡已驗收。

## 證據與限制

機讀證據包含輸入版本、批次 Seed 範圍、完成／失敗數、事件覆蓋、trace 數量、重複／冷卻／互斥違規、重播／排列置換／續玩比對、分國家家庭統計與可核對的完整人生樣本。失敗保留，不以重跑抹除。

此輪不執行 Simulator；不產生需清理的測試裝置。純 Swift 測試與批次模擬不能取代真人兒少試玩、實機、資料授權驗收或正式發布。

## 本輪原創候選與可重播路徑

| 定義 | 年齡／規則 | 實際後續用途 |
| --- | --- | --- |
| `rng-child-tool-library` | 8～12；一次；家庭有可用陪伴 | `join` 或 `ask` 留下 `tool-library/connection`，帶來源 occurrence 與設計假設 |
| `rng-community-practice` | 25～59；最多 3 次；間隔至少 10 年；健康至少 20 | 練習更新技能；每次有獨立 occurrence 與到期回應 |
| `rng-mutual-support` | 39～59；一次；照顧安排與既有 `adult-care/ask` 歷史 | 與社區練習互斥，提供另一條求助／互助敘事路線 |
| `rng-legacy-workshop` | 65～80；一次 | `host` 需已記錄借物聯繫及技能至少 28；未滿條件仍能求助／休息 |

既有每個固定年齡事件的權重為 2，新候選為 3；沒有依國名設定權重。每個槽都有專用、無額外條件的一次性既有事件，避免因條件過窄出現空池。國家環境條件能力以具來源的 synthetic boundary fixture 測試；本輪不為湊差異而把網路人口比例套用到無關的互助故事。

CLI 入口為 `swift run -c release life-demo --director-audit`，預設完整 1,024 段人生；`--seeds-per-context 2` 只作 16 段 smoke，不能代替主批次。每個主批次人生另執行同選擇重播、候選反序、中途序列化續玩，且逐一比對完整 session。

低資源／零材料、錯版本、竄改歷史、未知人物事實與實際長期後果另有 XCTest，不把它們混記為主批次工程人口樣本。`present:false` 必須有明確記錄，未知關係不等於已明確不存在。

## 本輪執行結果

- 最終套件：70 項 XCTest 通過（47 既有、23 事件導演）；包括不安全求助設定、完整人生結束後偽造選擇階段、極端歷史年齡、故事人物投影後的延遲回應、99／100 歲排程邊界，以及會被故事條件隱藏的選項不可充當唯一求助／休息路線。
- 主批次：1,024／1,024 完成人生；選事件 trace 與實際 ConsequenceTrace 各 15,360 筆。每段 15 個決策、五階段、80 歲回顧。
- 同決策重播、候選反序、中途續玩，各 1,024／1,024 完整 session 相同；這 3,072 段對照執行另計，不膨脹主樣本數。
- 19／19 定義都符合過條件且實際入選；無零覆蓋事件。窄條件 `rng-mutual-support` 僅 20 次符合、12 次入選；另有 KEN／家庭1／Seed 5／45歲的合法路徑。借物聯繫開啟晚年主持的對照路徑為 USA／家庭1／Seed 0／80歲。
- 1,448 次合法重複 occurrence、1,640 次已觸發延遲回應、680 筆實際關係事實；一次性／次數上限、冷卻、互斥、未合資格入選、trace 配對、可完成性及求助檢查違規皆為 0。
- 每家庭 128 個 Seed 有 75 種事件序列。這不是 75 份獨立劇本，也不能代替真人重玩意願驗收。
- 隔離副本中，移除排序、冷卻邊界改錯、忽略人物關係三個變異，均被具體測試 assertion 抓到。副本測完刪除；完整預期失敗 log 保留。

原始證據位於 `artifacts/rng/batch.json`、`artifacts/rng/logs/`、`artifacts/rng/mutations/`；修正 QA 前的成功批次保留於 `artifacts/rng/pre-qa/`，不冒充最終版本。`validation-manifest.json` 綁定來源與輸出雜湊。
