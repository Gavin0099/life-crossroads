## PR #1：模型

- `templateID` 是比較依據；不同國名、陣列位置與家庭顯示名稱不參與匹配。同 ID 必須具有相同條件，資料驗證會拒絕矛盾模板。
- 8、10、12、21 歲的面對面／紙本活動不套用網路、電力或設備排程規則。
- 只有明確需要連網的 13、17、25、45 歲選項使用數位情境規則，並各有獨立的紙本／社區老師學習路線。
- 相同第二家庭的 8 歲活動在四國均為時間 3、精力 2、材料 1，可以選擇；互助家庭均為時間 1。
- 全國比例仍只是明示的數位情境設計指數，不是家庭可用性或個人因果機率。
- schema 2 / data `lc01-data-2` / engine `lc01-2`，拒絕不相容舊輸入；原 WDI 來源 bytes 與版本保持不變。

驗證來源是審查者提供的失敗案例。先執行新測試，原模型的 Python 測試有兩項失敗、一項缺少模板欄位錯誤；Swift 三項測試共 14 個失敗斷言（含缺少離線選項的錯誤）。修正前輸出保留於 `artifacts/evidence/review/`，成功收據位於 `artifacts/evidence/test-results/pr1-model-review-*`。

## PR #2：接續要求

原因摘要只能列出實際產生影響的因素；資料被記錄、規則被檢查或一次運氣沒有發生，不等於它造成了資源變動。
比較必須使用玩家指定的 choice ID 與穩定家庭模板，並說明固定/變動條件。
至少三條前期選擇須改變後續人物、場景或可行選項，包含資源條件與恢復路線；固定 Seed 可重播。
視覺 Agent 與內容 Agent 在上述模型與摘要修正後並行，擬人化動物與場景須服務人物關係及選擇回饋。

### 已修正的原因與比較邊界

`contributingInfluences` 只統計實際套用選項、非零成本調整與非零資源效果；未發生的機會事件、被記錄但未使用的國家指標、零值上下限檢查不列為原因。成本疲勞屬遊戲規則，不會一概歸因國家環境。休息的回歸案例只顯示「你的選擇」。這個摘要解釋本次成本與資源變化，後續人物出場的條件另用故事分岔紀錄呈現。

比較入口逐項選擇實際 `choiceID`，不再固定 `invest`；家庭以 `templateID` 及相同條件匹配，不依陣列位置。測試特別只交換肯亞家庭的排序，並比較 `rest`，驗證選項、家庭、過去資源與種子確實固定。更換環境後的結果仍是設計模型內的比較。
