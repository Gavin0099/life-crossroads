# LL-09 真人試玩步驟與空白紀錄

狀態：準備用文件，**尚無真人結果**。工程／Simulator／AI目視不填入本表的玩家證據。沿用P1方向性試玩，10～12歲與13～15歲分開看；不作市場代表性推論。

## 開始前

- 填入實際安裝的commit／build與iPhone／iOS；未簽署的repo不是可安裝IPA。實機安裝與簽署另列，不使用TestFlight或上架替代本輪Draft。
- 只用測試編號與年齡組，不要求姓名、帳號或個人經歷；無須錄影或連網。
- 告訴玩家可以停下、暫停或略過演出，沒有唯一正確的人生。先讓玩家自己理解畫面，協助後要記錄協助發生在哪一步。

## 第一局：觀察，不教答案

1. 請玩家開始一段人生；記錄首次找到選擇、成本、暫停與跳過時是否需要提示。
2. 遊玩完整人生，人工計時；記錄讀不完、反覆捲動、想跳過、期待下一件事、找不到角色或不懂圖示的位置。
3. 觀察8／13／17歲的實際路線；若沒有遇到相應選擇或呼應，記「未遇見」，不把示範路線塞進玩家歷史。
4. 完成後先問「接下來你想做什麼？」記錄是否自發重玩；不以大人要求、獎勵或提問暗示作為自發重玩。

## 理解與第二局

- 問「你覺得哪個選擇影響了後來？從哪裡看出來？」只記玩家實際答案，對照該局trace，區分答得出、需要提示、誤解與未遇見。
- 問「有哪些事情你能改變？有哪些需要別人或環境幫忙？」不先提供國家優劣或努力必勝的答案。
- 若玩家想探索，讓他自己選擇同背景換運氣、回到岔路或跨環境比較。記錄其選擇、原局是否可找回、是否理解後續又做了其他決定。
- 待發生線索不算已獲得機會；另一條人生是模型比較。若孩子混淆，記錄畫面與原話後再說明。
