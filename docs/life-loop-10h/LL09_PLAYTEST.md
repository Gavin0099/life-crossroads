# LL-09｜真人試玩主持步驟

狀態：**材料已準備，尚無真人結果**。使用者安排 iPhone 與 10～15 歲玩家；搭配[每人記錄表與分齡彙整](LL09_RECORDS.md)。沿用 P1 的 8～10 人方向性觀察，實際人數照實填；10～12 歲與 13～15 歲分開看，不作市場代表性推論。

## 事前準備（主持人自行完成）

1. 在 Mac 記下實際測試 checkout 的 `git rev-parse HEAD`、是否有未提交的 App 修改，再從 Xcode 開啟 `LifeCrossroads.xcodeproj`，選 LifeCrossroads scheme、自己的開發簽署與實體 iPhone 執行。記錄裝置、iOS、安裝日期及實際可取得的 build 資訊；首頁「P1 整合預覽 0.1」不是 commit 證明。目前沒有已簽署的交付包或 TestFlight 版本。
2. 不帶 `-ui-testing` 或保存故障等測試參數。首頁開啟「生活世界預覽」，記錄字級、短文與減少動態效果設定；允許孩子調整，並記錄時點。先由成人確認可開新局、可存續玩與可回首頁，結果填「實機檢查」，不填成孩子表現。
3. 每人複製一份表，編號 P01、P02……；只填年齡組，不收姓名、生日、帳號或個人經歷。取得家長／照顧者同意與孩子願意參加；可以隨時停下，無須錄影，也不必連網。
4. App 只保存一組原局與試走路線；「建立新人生」會取代這組記錄。換玩家或換 Seed **以前**，先記下前一局的背景、Seed、選擇與必要畫面。試玩中不更新版本；版本變動另開批次。
5. 填好的表與可選截圖留在主持人的本機私人資料夾，**不要提交到公開 repo 或 PR**；repo 只放空白模板。需回報時先整理匿名、去識別的觀察。

## 開場照讀（約 1 分鐘）

> 今天想請你玩一段沐沐的人生，看看遊戲哪些地方清楚、哪些地方讓你困惑。我們是在測遊戲，不是在考你。選擇沒有唯一正確答案，你可以依自己的想法玩，也可以暫停或隨時停止。如果你願意，可以說說你正在想什麼；不想說也沒關係。

先不要教按鈕位置、指定選項、解釋國家差異，或告知哪個選擇有後續獎勵。卡住時先記錄，再問「你現在想做什麼？」；需要操作協助就幫忙，記下提示內容，不讓孩子一直受困。

## 流程與計時

預留每人約 25～35 分鐘，包含設定、第一局、短訪談與自願探索；這是帶測時間建議，**不是遊戲實測時長**。首局目標仍為 10～15 分鐘，不到點催快或為達標提早結束。

| 順序 | 主持人怎麼做 | 要記什麼 |
| --- | --- | --- |
| 1 起點 | 「請你開始一段人生，起點可以自己選。」若不想選，可用預設日本／家庭一，記為主持指定。 | 國家、家庭、當局 Seed、誰選起點。Seed 是實際畫面值，不要求孩子輸入。 |
| 2 第一局 | 從按下「陪沐沐開始一段人生」計時，到人生回顧或玩家停止；自由選擇。 | 起訖、總經過時間、訪談或外在中斷、完成與否及原因；扣除中斷的估計另列，不覆寫總時間。 |
| 3 操作觀察 | 安靜看玩家如何找選項、成本、全文、暫停與跳至事件，不要求逐項找齊。 | 獨立操作／提示、閱讀捲動／誤觸、期待／想跳過的具體事件與原話；沒發生就填未觀察。 |
| 4 後果觀察 | 留意實際遇見的 8／13／17 歲選擇與角色／道具反應。 | 當次選項、看到什麼、是否把待發生線索當成已得到的結果；未遇見不補寫示範歷史。 |
| 5 中立停頓 | 首局結束先問「接下來你想做什麼？」留思考空間，再談理解；不要先問要不要重玩。 | 主動開始、主動想試但未開始、只看回顧、停止，或經提示才探索；分開記。 |
| 6 短訪談 | 用下面問題詢問，原話先記、事後才核對。 | 獨立回答／操作提示後／內容提示後／誤解／證據不足，不給孩子人生分數。 |
| 7 自願探索 | 想繼續才讓玩家選岔路、換運氣或換環境；時間不足可只記想法。 | 動機、實際操作、新故事、原局是否保留及理解。沒有走完不記成完整後半生驗收。 |

## 首局後的中立問題

LX-01～LX-03版另觀察玩家是否自行找到「這段人生的重心」、是否知道下一段才生效，以及是否誤以為等待動畫或重複點選會多拿資源。先記自主操作，之後才提示。若做「5秒看懂人生」專項，另開批次並記是否初次見到畫面，問角色／年齡與階段／當前處境／下一步能做什麼；不與未受提示的自由首局混算，也不把熟悉後辨識當初見理解。

按情況問，不必全問，也不先給答案。說不記得就照實記錄，之後才一起找畫面。

- 「這一生你最記得哪件事？有哪一刻想知道接下來會怎樣？」
- 「有沒有一個選擇，讓後來的故事變了？你從哪裡看出來？」
- 「你做那個選擇時，付出了什麼、留下了什麼？」
- 「哪些事你能決定？哪些需要別人幫忙，或不是你能決定的？」
- 若自行打開跨國比較：「你看到哪些相同、哪些不同？畫面怎麼說明？」
- 若自行回到岔路：「原本那段人生在哪裡？你覺得兩條路為什麼不同？」

訪談後由主持人核對當局「為什麼會這樣？」、故事記錄、時間軸或比較頁。記下事件／年齡、選項與核對位置；只看到 UI 時標為**畫面核對**，不聲稱已檢查原始 ConsequenceTrace。需要工程核對時保留版本、背景、Seed 與逐步選擇；資料不足填無法判斷，不由 AI 補因果。

## 探索操作備查（自由首局不要先念）

| 玩家想做什麼 | 現有操作與限制 |
| --- | --- |
| 回到一次選擇 | 完成人生後「回到一個重大岔路」，自選改選並親自走完後半生；完成替代路線後才有「比較完整後半生」。用「看看保留的原人生」找原局，記錄後續又做了哪些選擇。 |
| 同起點換運氣 | 回顧頁「同背景，換個運氣」；先記原局，確認取代提示後才開始，記下新 Seed。有些故事仍可能相同。這不是保留兩局的岔路功能。 |
| 完全重玩 | 「同背景、同種子，再走一次」還須做相同選擇才是重播；不同選擇不能當作 Seed 失效。此操作也會取代目前的一組人生。 |
| 看環境差異 | 事件或後果比較入口可選指定行動；允許成本相同、資料未知或替代路線不同。不暗示每國必然有差異，不把資料缺口當成沒有服務。 |

## 結束後

- 謝謝玩家；困惑是改善遊戲的線索，不評斷其人生選擇。有誤解時先記原話，再說明這是虛構模型、共用河畔不是各國實景。
- 完成[記錄表與彙整](LL09_RECORDS.md)，娛樂、理解、操作三類觀察分開；事實、主持解讀與待核對原因也分開。
- 實機、人工 VoiceOver、真人時長、理解與自發重玩各自列證據。沒用 VoiceOver 填未測；沒有真人資料時，**LL-09 維持待驗收**。不以 CI、Simulator、AI 目視或材料完成取代產品通過。
