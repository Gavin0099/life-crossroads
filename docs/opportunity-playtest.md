# LX-05｜先不看數字的兩段人生

本片工程驗證不能代替下列真人觀察。沿用LL09同意／隱私／退出安排；不記錄姓名，不把孩子的回答評成對錯。

1. 使用同版本、同Seed34、家庭一，分別開日本／肯亞探索人生；13歲同選線上圖解。17歲讓玩家先讀情境與可行選項，不先解釋設計目的。可沿各自協作邀請走到25歲；若玩家另選，照實記錄，不帶回指定答案。
2. 問：「這兩段故事有什麼相同？有什麼不同？」接著問：「你覺得什麼影響了這次能做的事？」不要先說設備、老師或國家，也不要求每國都不同。
3. 記錄玩家引用的具體情節、自己認為的原因、是否把虛構家庭當作全國人都一樣，以及是否主動想再試其他選擇。
4. 最後才打開「為什麼會這樣？」及單事件快比，核對玩家理解與實際紀錄。告知這是遊戲模型，國家平均不決定個人人生，台灣部分資料目前未知。
