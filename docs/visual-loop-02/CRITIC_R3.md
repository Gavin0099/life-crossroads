## 仍保留的限制

1. **年齡仍不能精確盲讀。** 成人與較年輕角色有部分區別，但 13／17 歲缺少穩定外觀差異；不能用畫面文字倒推「插畫年齡已被辨認」。
2. **結果不能由畫面編造。** 有酬、成功、協助有效性、恢復量、短時參與的時間長度仍需已保存狀態／文字證據；共同持材料只證明可見參與。
3. **求助與選擇前邊界仍採 R2 的已見證據。** R2 的 13-ask 只表達提問，13-before 保持空手中立；本輪未重看這兩張的雙尺寸全模式，不宣稱擴大覆核。
4. **不是完整可用性證明。** 不以截圖判斷所有控制可達、VoiceOver、動態效果或真實操作結果；主流程 UI 測試是獨立證據，本 Critic 未重跑。
5. **不是正式美術或真人通過。** 全部結論來自 AI 目視原生 Simulator 截圖，沒有真人玩家、適齡讀者或實機驗收；既有的大字型標題多行換行仍屬可改善的布局密度。
6. **本輪實看範圍有界。** Round3 共直接目視 26 張圖片（SE 13、iPhone 17 13）。remote 為指定兩尺寸三模式完整核對；其他核心活動為列明的抽查，不宣稱逐張看完主流程全部矩陣。
