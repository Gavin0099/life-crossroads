## 正確保留的語意邊界

- **I 的「未看到協助」是符合映射，而非缺陷。** 攤掌、張嘴與抱筆記本已支持提出問題的姿態。只能修正眼神目標，不應要求貓頭鷹解題、遞工具或展示已成功支持。
- **C 不應預先參與 H 的活動。** 現有閉眼休息可保留；不需要為了顯示「恢復重心」再加上可量化康復或新任務成功的圖像。
- **M 必須保持選擇前。** 中立站姿與共同工作室合理，不要加入已寫、已黏、已連線、已接受導師操作等承諾行為。
- **A 的有酬性可由已記錄文案交代。** 不要求畫面憑空增加現金、付款成功或客戶肯定。
- **H 的短時性不必畫出假的計時證據。** 現有參與行為可支持「參加活動」；時長屬於文字／狀態，不必為求視覺辨識編造。
- **年齡只採粗類別。** A/F/C/H 成人感與設定大致相容；B/D/E/G/I/J 的青少年感並不穩定，但不能要求單張卡通插畫證明精確 13 或 17 歲。K 的兒童感和 L 的長者外觀有可見區別。

## 尚需處理的 P1 / P2

此處 P1 指會明顯誤示未發生的主要活動或破壞選擇前後語意；P2 指直接妨礙本輪核心活動／互動辨讀的可見問題。以下都是第一輪狀態，主代理宣告準備修正不算已修正。

### P1

**A–J 未發現需要另開 P1 修改的可見錯誤。** 特別是 I 沒有表現「已得到協助」，符合要求。M 舊圖帶同伴持圖講述與殘留介面，不宜當作新的選擇前驗收證據；主代理已安排替換，第二輪需確認中立畫面沒有預先執行任何選項。

### P2：已納入主代理準備修改的項目

1. **G：視訊對象需歸屬實際螢幕。** 現有肖像框像浮在房間中，降低「remoteStudio」可讀性。把它接進實際螢幕是對症修正；完成後要保留方塊工作內容、遠端對象及主角指向對象的空間關係，不能用大視訊框蓋住全部正在討論的內容。
2. **F / I：讓目光指向真正在場的同伴或共同工件。** 第一輪主角看向右上，而同伴位於較低位置；調整同伴位置／比例或主角目光均可。I 不需要對方增加協助行為。F 不需要因放大同伴而遮住手或板件。
3. **M：替換時去掉殘留 UI，檢查接地。** 第一輪空白色塊與貓頭鷹腳爪／長椅／地面陰影層次不清楚，不應帶進新基準畫面。同一工作室和中立姿勢有助於和後續選擇一致；這些變化尚未經圖片驗證。

### P2：上述方案之外，仍應補的一項

4. **D / F：如果驗收名稱保留「共作」，需給已提交的同伴一個清楚、有限的材料參與動作。** 第一輪 D 最多看出貓頭鷹在桌角附近，F 最多看出它看著零件；只把 F 同伴放大和接地，仍不能把「站旁邊」變成「共同製作」。D/F 均已映射為選定共作，可把現有同伴的一翼明確放在、扶住或整理既有板材，讓同一桌的工作關係可見。不要擴張成替主角完成作品、證明成功、收款或新增未記錄承諾。這是已選活動的辨識修正，**不適用於尚未確認支持的 I，也不適用於選擇前的 M**。

D/F 的此項限制不否定四組已有實質活動差異；它只限制目前可將畫面稱為「共作」到什麼程度。若產品驗收只要求「實體工件與同伴在場」，而不要求「同伴參與材料活動」，應明確降低該語意主張，不能由評論者自行把在場當成已提供協助。
